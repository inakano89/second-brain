✅ Primeiros passos

Você não precisa configurar tudo de uma vez. Uma ordem recomendada:

  1. Uma chave de IA (Gemini tem plano gratuito — é o jeito mais rápido de começar). Veja Chaves de IA.
  2. Telegram para capturar notas, áudios e fotos pelo celular. Veja Telegram.
  3. Mais uma ou duas IAs (Claude, GPT) para usar o Conselho, em que os modelos debatem antes de decidir.
  4. Google (Agenda, Gmail, Drive, Contatos, Tasks, YouTube) e Zepp para o briefing matinal ficar completo. Depois, o Takeout traz o histórico do YouTube, pesquisas, Maps e Keep.
  5. Backup para outro lugar (S3, WebDAV ou Telegram).

Onde colar as chaves: menu Configurações → Variáveis (.env). Campos de senha ficam ocultos depois de salvos (é normal).

🧠 Chaves de IA (API keys)

Uma API key é uma senha que permite ao Second Brain usar a IA de uma empresa. É diferente da assinatura do app de chat (ChatGPT Plus / Claude Pro não servem): a API é cobrada por uso, normalmente centavos por dia.

  • Guarde a chave em local seguro e nunca a compartilhe.
  • Defina um limite de gasto no site do provedor.
  • Depois de colar a chave, vá em Modelos e clique em Testar.

Claude (Anthropic)

  1. Acesse console.anthropic.com e crie uma conta.
  2. Em Billing, adicione créditos (ex.: US$ 5) e, se quiser, um limite mensal.
  3. Abra API Keys → Create Key, dê um nome (ex.: “second-brain”) e copie a chave (começa com sk-ant-). Ela aparece só uma vez.
  4. No Second Brain: Configurações → LLM → Anthropic (Claude) API key → cole → Salvar e aplicar.

GPT (OpenAI)

  1. Acesse platform.openai.com/api-keys e entre.
  2. Em Settings → Billing, adicione créditos.
  3. Clique Create new secret key e copie (começa com sk-).
  4. Cole em Configurações → LLM → OpenAI API key. A OpenAI também habilita a transcrição de voz (Whisper).

Gemini (Google) — tem plano gratuito

  1. Acesse aistudio.google.com/apikey com sua conta Google.
  2. Clique Create API key e copie (começa com AIza).
  3. Cole em Configurações → LLM → Google Gemini API key.

O Gemini lê imagens, PDFs e áudios — ótimo para OCR e transcrição. No plano gratuito o Google pode usar os dados para melhorar produtos; para dados sensíveis, ative o faturamento.

Modelo local (Ollama) — grátis e privado

  1. Instale o Ollama em um computador com boa memória (8 GB+ de RAM).
  2. No terminal: ollama pull llama3.1 (e, para embeddings, ollama pull nomic-embed-text).
  3. Em Configurações → LLM → LLM local, informe http://IP-DO-COMPUTADOR:11434/v1. Se o Second Brain roda no mesmo computador: http://localhost:11434/v1. No Docker: http://host.docker.internal:11434/v1.
  4. Para acessar de outra máquina, inicie o Ollama com OLLAMA_HOST=0.0.0.0.

🧩 Modelos e Conselho

  1. Menu Modelos: cada empresa tem um modelo padrão (★). Adicione ou remova modelos; use “Ver modelos disponíveis na sua conta” para escolher da lista oficial.
  2. Em Qual modelo faz cada tarefa, escolha para cada ação (chat, Telegram, OCR, briefing…) um modelo específico, o padrão de uma empresa, “Automático” ou 🤝 Conselho.
  3. No Conselho, os membros respondem, leem as respostas dos outros e revisam; um moderador escreve a decisão final. Use em decisões importantes (briefing, revisões). É ~7× mais caro que um modelo só com 3 membros e 1 rodada.
  4. No Chat, o seletor no topo troca o modelo na hora; no Telegram use /model.
  5. A lista de modelos se atualiza sozinha. Todo dia o Second Brain baixa a lista recomendada do projeto: modelos novos aparecem, os descontinuados somem e o ★ padrão acompanha a recomendação. Se você escolheu outro padrão, ele é mantido. Para forçar, clique em 🔄 Sincronizar agora; para desligar, desmarque Atualizar lista de modelos de IA automaticamente em Configurações → Atualizações.

Dica de custo: deixe Auto-tagging num modelo barato (ex.: Claude Haiku ou o mais barato de cada empresa) — ele roda em toda nota nova. A página Modelos mostra o preço de cada um (US$ por 1 milhão de tokens).

💬 Telegram (2 minutos)

  1. No Telegram, abra o @BotFather (selo azul oficial) e envie /newbot.
  2. Escolha um nome (ex.: “Meu Cérebro”) e um usuário terminado em bot (ex.: meucerebro_bot).
  3. O BotFather envia um token parecido com 123456789:AAH.... Copie.
  4. Cole em Configurações → Telegram → Token do bot e salve. Os IDs autorizados podem ficar em branco.
  5. Abra seu bot no Telegram e toque em Iniciar (/start). Ele responde com seu ID.
  6. No painel: Configurações → Telegram → Aguardando autorização → Autorizar. Pronto! Só pessoas autorizadas conseguem usar o bot.

O que enviar: texto (conversa com a IA), áudio (vira nota transcrita), foto (OCR), PDF, e comandos como /task comprar pão, /event amanhã 15h dentista, /brief, /help.

🔗 Google: Agenda, Gmail, Drive, Contatos, Tasks e YouTube

É a configuração mais longa (~10 min), feita uma única vez. Você cria um “aplicativo” particular no Google que só você usa. Tudo é somente leitura, com duas exceções: criar eventos na agenda e criar rascunhos no Gmail (o Second Brain nunca envia e-mails; você revisa e envia).

Pré-requisito: acessar o Second Brain por HTTPS com domínio (veja HTTPS) ou por http://localhost. O Google não aceita IPs nem HTTP em outros endereços.

  1. Abra console.cloud.google.com e crie um projeto (ex.: “second-brain”).
  2. Em APIs e serviços → Biblioteca, pesquise e clique Ativar em cada uma: Google Calendar API, Gmail API, Google Drive API, People API (contatos), Google Tasks API e YouTube Data API v3. Pule as que não quiser usar.
  3. Em Google Auth Platform (tela de consentimento OAuth): tipo Externo, nome do app, seu e-mail de suporte. Em Público-alvo → Usuários de teste, adicione o seu Gmail.
  4. Em Clientes → Criar cliente: tipo Aplicativo da Web. Em URIs de redirecionamento autorizados, cole exatamente:
    {{.RedirectURL}}
    Se aparecer localhost e você usa domínio, primeiro preencha URL pública em Configurações → Geral.
  5. Copie o ID do cliente e a Chave secreta para Configurações → Google e salve.
  6. Clique Conectar Google. Na tela “o Google não verificou este app”, clique Avançado → Continuar (o app é seu). Marque todas as caixas de permissão e confirme.
  7. Importante: em Público-alvo, clique Publicar app (“Em produção”). Em modo “Teste” o Google desconecta a cada 7 dias.

O que é importado (a tabela em Configurações → Google mostra o estado de cada um):

  • Agenda: todas as agendas visíveis (inclusive aniversários e feriados), o último ano de eventos e os próximos 14 dias. Participantes viram ligações com seus contatos.
  • Gmail: e-mails importantes viram notas e tarefas; no chat, a IA pode buscar e ler qualquer e-mail e criar rascunhos de resposta.
  • Drive: Documentos, Planilhas, Apresentações, PDFs, Word e textos alterados no último ano (ajuste em DRIVE_SINCE_DAYS; filtre com DRIVE_QUERY, ex.: 'me' in owners).
  • Contatos: cada contato vira uma pessoa no grafo (e-mails, telefones, empresa, aniversário, anotações).
  • Google Tasks: suas tarefas e listas (só leitura: concluir aqui não conclui lá).
  • YouTube: vídeos curtidos, canais inscritos e playlists. O histórico não tem API — use o Takeout.

Já estava conectado antes? Clique Reconectar e autorizar em Configurações → Google para liberar os serviços novos. Para desligar algum, remova-o de GOOGLE_SERVICES.

Sem API (limitação do Google): Google Fotos (desde 2025 só fotos criadas pelo próprio app), Keep (só contas corporativas), Play Store, Linha do tempo do Maps e histórico do YouTube/Chrome. Quase tudo isso chega pelo Takeout.

📦 Google Takeout (histórico do YouTube, pesquisas, Maps, Play, Keep)

O Google Takeout exporta seus dados num arquivo .zip. O Second Brain lê o arquivo e cria notas mensais (ex.: “YouTube — vídeos assistidos — setembro de 2026”), com os itens mais frequentes no resumo.

  1. Abra takeout.google.com e clique Desmarcar tudo.
  2. Marque: Minha atividade, YouTube e YouTube Music, Chrome, Maps (seus lugares), Salvos, Google Play Store, Keep e, se existir, Histórico de localização (Linha do tempo).
  3. Em Minha atividade e em YouTube, clique Vários formatos e troque HTML por JSON. Sem isso o histórico não é importado.
  4. Clique Próxima etapa. Escolha o formato .zip e o destino:
    • Adicionar ao Drive + Exportar a cada 2 meses por 1 ano (recomendado): com o Drive conectado, o Second Brain baixa e importa sozinho (CRON_TAKEOUT).
    • Enviar link por e-mail: baixe o .zip e envie em Importar, ou copie para a pasta inbox (melhor para arquivos acima de IMPORT_MAX_MB).

Linha do tempo do Maps: desde 2024 ela fica só no celular. No app Google Maps: foto do perfil → Configurações → Conteúdo pessoal → Exportar dados da Linha do tempo. Envie o Timeline.json (no iPhone, location-history.json) em Importar, ou coloque-o dentro de um .zip na pasta inbox.

Importar de novo é seguro: meses que não mudaram são ignorados. Anúncios assistidos no YouTube são descartados. Keep, contatos (.vcf), agendas (.ics) e listas salvas do Maps (.csv) do mesmo .zip vão para os leitores próprios da página Importar. A exportação pode ser grande: selecione só os itens acima.

❤️ Zepp / Amazfit

  1. Use o e-mail e senha da sua conta Zepp (se você entra com Google/Apple, defina uma senha no app ou use a alternativa abaixo).
  2. Cole em Configurações → Zepp. A sincronização roda a cada 4 horas (sono, frequência cardíaca em repouso, passos).

A API do Zepp não é oficial e pode mudar. Alternativa estável: envie os dados via webhook (Gadgetbridge, Health Connect + app “HTTP Shortcuts”, Home Assistant) para {{.PublicURL}}/api/health/webhook com o API token (Configurações → Web Clipper & API).

📰 RSS

  1. Encontre o endereço do feed do site (geralmente /feed, /rss ou ícone laranja).
  2. Cole um por linha em Configurações → RSS → Feeds.
  3. Descreva seus interesses (ex.: “IA aplicada, finanças pessoais, corrida”). A IA dá nota 0–10 a cada notícia e salva só as relevantes.

✂️ Web Clipper (salvar páginas)

  1. Mostre a barra de favoritos do navegador (Ctrl+Shift+B).
  2. Em Configurações → Web Clipper, arraste o botão 🧠 Salvar no Brain para a barra.
  3. Em qualquer página, selecione um trecho (opcional) e clique no favorito. Sem seleção, a página inteira é resumida.

🗺️ Mapa (tela inicial)

A Visão geral mostra tudo em anéis: no centro o seu cérebro; em volta, as rotinas (verde = rodou bem, vermelho = erro); depois os tipos (notas, tarefas, pessoas…), os temas mais frequentes e, por fora, as fontes de onde as coisas chegam. Quanto maior o círculo, mais itens.

Passe o mouse para ver as ligações (ex.: o que veio do Gmail vira nota e tarefa). Clique para ver a lista no painel da direita e, de lá, Ver na rede para explorar as conexões de cada nota. A aba Rede mostra o grafo completo.

📂 Pasta inbox

Arquivos colocados na pasta inbox (ao lado do .env) são lidos automaticamente: PDFs, fotos, áudios, .md, .txt e arquivos .zip exportados de outros apps (Obsidian, Notion, Google Takeout… — veja Importar). Depois são movidos para inbox/.archive. Dica: sincronize essa pasta com Syncthing/Dropbox para “jogar” arquivos do celular.

📥 Importar de outros apps

Traga o que você já tem em outros aplicativos: abra Importar no menu, escolha o arquivo exportado e clique em Importar. O formato é reconhecido sozinho, e importar de novo o mesmo arquivo não duplica nada.

  • Obsidian / Logseq: compacte a pasta do vault em .zip (botão direito → Compactar/Enviar para → Pasta compactada) e envie o .zip.
  • Notion: Settings → Export all workspace content → formato Markdown & CSV. Envie o .zip baixado, sem descompactar.
  • Evernote: selecione as notas (ou clique com o botão direito no caderno) → Exportar → formato ENEX.
  • Google Keep: acesse takeout.google.com, clique em Desmarcar tudo, marque só Keep e exporte. Envie o .zip.
  • Google Takeout completo (histórico do YouTube, pesquisas, Chrome, Linha do tempo, Maps, Play Store): veja Google Takeout.
  • Favoritos do navegador: Chrome/Edge: Ctrl+Shift+O → ⋮ → Exportar favoritos. Firefox: Ctrl+Shift+O → Importar e fazer backup → Exportar para HTML. Marque “baixar o texto de cada página” para ler os artigos depois.
  • Planilhas (Excel, Google Sheets): Arquivo → Salvar como → CSV. Nomeie as colunas como título, conteúdo, tags, prazo… (linhas com prazo viram tarefas). Exportações CSV do Todoist, Readwise, Goodreads e Pocket também funcionam.
  • Kindle: ligue o Kindle no computador pelo cabo USB e envie o arquivo documents/My Clippings.txt. Cada livro vira um artigo com seus destaques.
  • Contatos: contacts.google.com → Exportar → vCard. No iPhone: iCloud.com → Contatos → ⚙️ → Exportar vCard.
  • Agenda: Google Agenda → ⚙️ Configurações → Importar e exportar → Exportar (baixa um .zip com os .ics). Outlook: Salvar calendário.
  • Feeds (Feedly, Inoreader): exporte o OPML; os feeds entram direto na lista de RSS.

💰 A caixa “Analisar cada item com IA” faz resumo e tags por inteligência artificial, mas custa ~1 chamada por item. Para importar milhares de notas, deixe desmarcada: a busca, as tags e as conexões funcionam mesmo assim. Depois, use “Reprocessar” só nas notas que quiser.

Importou algo por engano? Em Conteúdo → Envios você apaga a importação inteira de uma vez (e desfaz, se precisar).

Arquivo muito grande? O limite é IMPORT_MAX_MB (200 MB por padrão, em Configurações → Geral). Se o servidor fica atrás do nginx, aumente client_max_body_size. Ou copie o arquivo para o servidor e rode second-brain -env .env -import arquivo.zip.

🗂 Conteúdo: editar e apagar

No menu Conteúdo ficam, em lista, todas as notas, tarefas, favoritos, e-mails e demais itens que entraram no seu cérebro. É o lugar para arrumar tudo de uma vez, em vez de apagar um por um.

  1. Filtre: digite parte do título ou do texto, ou escolha o tipo, a origem (por exemplo “Importação: Favoritos”, “Gmail”), uma tag ou um período.
  2. Selecione: marque a caixinha dos itens (ou clique na linha). Para marcar vários seguidos, clique no primeiro e, segurando Shift, no último. A caixinha do cabeçalho marca a página inteira e, em seguida, aparece o botão Selecionar todos os resultados para pegar tudo o que o filtro encontrou.
  3. Escolha a ação na barra que fica presa no topo: Apagar, + Tag/− Tag, Mudar tipo, Concluir/Reabrir tarefas, Reprocessar IA ou Exportar (baixa um .zip que abre no Obsidian). No celular, as ações extras ficam em Mais ações.

Clique no título de um item para ler, editar ou apagar no painel ao lado, sem sair da lista. Os botões de Faxina mostram itens duplicados, sem conteúdo e sem conexões — bons candidatos para limpar.

Envios mostra cada importação (por exemplo, o arquivo de favoritos) e cada origem com a quantidade de itens: dá para ver ou apagar tudo de uma vez.

Lixeira: nada some na hora. O que você apaga fica 30 dias na lixeira e pode ser restaurado com as conexões (logo depois de apagar aparece o botão Desfazer). Depois de 30 dias é removido de vez automaticamente.

🚫 Não trazer de volta (já vem marcado): impede que o Google, o RSS, o Zepp ou uma nova importação do mesmo arquivo tragam de novo o que você apagou. Se você mesmo reenviar pelo Telegram, pela web ou pela pasta inbox, o item volta. Mudou de ideia? Lixeira → Permitir que voltem.

🧠 Memória, tarefas de reuniões e faxina

Três rotinas trabalham sozinhas para o seu cérebro não virar um depósito. As duas primeiras usam a inteligência artificial configurada em Chaves de IA; a faxina não custa nada.

  • 📝 Tarefas de reuniões (ao meio-dia e às 18h): lê anotações, atas e transcrições de reuniões que você salvou (por exemplo, uma nota chamada “Reunião com a equipe”, as “Anotações do Gemini” do Google Meet no Drive ou um áudio longo no Telegram) e cria as tarefas combinadas, com prazo quando alguém disse “até sexta”. O que ficou com outra pessoa vira “Aguardando Fulano: …”. Em seguida você recebe no Telegram a lista de tarefas novas, inclusive as que vieram dos e-mails.
  • 🧠 Memória (às 22h30): resume o dia em decisões, aprendizados e prioridades atuais, tirados das suas notas, reuniões, e-mails e conversas com o assistente. O chat passa a lembrar disso (“o que eu decidi sobre o banco?”) e o briefing da manhã leva as prioridades em conta. Tudo fica em Conteúdo → tag memoria.
  • 🧹 Faxina semanal (domingo, 17h30): procura cópias, textos quase iguais, tarefas esquecidas há mais de um mês, notas vazias e pessoas que a IA criou por engano. Nada é apagado sozinho: você revisa em Conteúdo → Faxina e escolhe Juntar, Apagar, Concluir ou Manter (a sugestão não volta). O que for apagado fica 30 dias na lixeira.

Tudo aparece no topo do Painel: números da semana, briefing de hoje, lista A fazer (atrasadas, de hoje e novas da IA — ✓ conclui, ✕ descarta uma sugestão errada), prioridades e decisões recentes.

Quer mudar os horários? Em Configurações → Agendamentos: CRON_ACTIONS, CRON_MEMORY e CRON_CLEANUP (use off para desligar). O modelo de IA de cada uma se escolhe em Modelos.

🪪 Perfil: saúde, rotina e datas

O menu Perfil guarda as informações fixas da sua vida, organizadas em abas. A Visão geral junta tudo: o que você tem para hoje, os próximos 30 dias e um resumo.

  • 🪪 Sobre mim: nome, documentos, tipo sanguíneo, plano de saúde, endereços (casa, trabalho), contatos de emergência, alergias e preferências.
  • 🩺 Saúde: medicações contínuas (dose, horários, estoque, validade da receita), suplementos, dieta (metas de calorias e macros, nutricionista), condições, cirurgias, vacinas, exames e seus médicos (com “retorno a cada N meses”).
  • 🗓️ Rotina: matrículas (academia, escola, inglês…) com dias da semana e horário opcional, mensalidade e renovação; cursos, assinaturas e hábitos.
  • 🎂 Datas: aniversários, casamento e outras datas que se repetem, e viagens. Os aniversários dos seus Contatos do Google entram sozinhos. Nessa aba aparecem sugestões do Google Agenda: eventos que parecem cirurgia, consulta, exame, vacina, curso, viagem ou aniversário. Clique em Adicionar e complete os detalhes.
  • 🏠 Casa e bens: documentos com validade (CNH, passaporte), veículos (revisão, seguro, IPVA), manutenção da casa, contas fixas, pets e garantias.
  • 🎯 Metas: objetivos com prazo, progresso e próximo passo.
  1. Abra a aba, clique em + Adicionar, preencha o que souber (só o nome é obrigatório) e salve.
  2. Para medicações e suplementos, informe os horários (ex.: 08:00, 20:00) e o estoque. Você recebe o lembrete no Telegram na hora certa; responda /tomei 12 (o número vem na mensagem) ou marque em Perfil → Hoje. O estoque diminui sozinho e você é avisado quando estiver acabando.
  3. Matrículas e cursos com horário geram um aviso antes da aula (60 minutos por padrão, em REMINDERS_CLASS_BEFORE).

O balanço das 21h ganha o bloco “Amanhã e próximos 7 dias” (doses, aulas, vencimentos, aniversários, estoque baixo) e o briefing das 7h o bloco “Hoje na sua rotina”. No Telegram, /hoje mostra o mesmo a qualquer hora. No chat, pergunte “que remédios eu tomo?” ou “qual meu horário da academia?”.

🔒 Privacidade: itens marcados como sensíveis (saúde, documentos e endereços já vêm marcados) ficam cifrados no banco, aparecem ocultos nas listas até você clicar em 👁 Mostrar (cada exibição fica no Audit log) e, por padrão, não são enviados a IAs na nuvem: só um modelo local os lê. Mude em Configurações → Perfil → PROFILE_AI_ACCESS (basic, full ou none). Para a IA preencher o Perfil por você (“cadastre minha Losartana 50 mg às 8h e 20h”), ligue PROFILE_AI_WRITE em Configurações → Perfil: ela só cria e atualiza itens, nunca apaga nem muda a marca “sensível”, e a conversa fica cifrada. Os lembretes e os blocos pessoais dos relatórios vão direto para o seu Telegram, sem passar pela IA; se o Telegram estiver fora do ar, a cópia guardada para reenvio também fica cifrada.

Conversas do chat em que a IA consultou o Perfil são guardadas cifradas, não entram na rotina de Memória e só são reenviadas como contexto a um modelo que pode ver esses dados (local, ou todos com full).

Quer cifrar todos os itens do Perfil, inclusive matrículas, datas e metas? Ligue Criptografar todos os itens do Perfil (PROFILE_ENCRYPT_ALL) em Configurações → Perfil. A marca “sensível” continua decidindo o que fica oculto na tela e o que a IA pode ler.

A chave que cifra esses itens (VAULT_KEY) é criada sozinha no .env. Uma cópia dela fica no banco, protegida pela chave de backup: se você perder o .env mas tiver a chave de backup, os itens voltam a abrir.

🔐 Backup

Os backups são cifrados com a chave mestre definida no setup. Guarde essa chave fora do servidor (gerenciador de senhas) — sem ela não há como restaurar.

  • Telegram (mais fácil): em Configurações → Backup → Destinos, escreva local,telegram. O arquivo chega no seu chat (limite 50 MB).
  • Backblaze B2 / Cloudflare R2 / AWS S3: crie um bucket e uma chave de aplicação; preencha S3_ENDPOINT (ex.: https://s3.us-west-004.backblazeb2.com ou https://<conta>.r2.cloudflarestorage.com), região (auto no R2), bucket e chaves; destinos local,s3.
  • Nextcloud (WebDAV): URL https://sua-nuvem/remote.php/dav/files/USUARIO/backups, usuário e senha de app; destinos local,webdav.

Restaurar: second-brain -decrypt arquivo.db.enc -out brain.db, pare o serviço e substitua data/brain.db.

🖥️ Instalação

Linux (VPS, Raspberry/Orange Pi) — sem Docker

curl -fsSL https://raw.githubusercontent.com/inakano89/second-brain/main/deploy/install.sh | sudo bash

Detecta a arquitetura (x86-64, ARM64 ou ARMv7), verifica o SHA-256, instala em /opt/second-brain, cria o serviço systemd e mostra o endereço. Atualizações automáticas funcionam normalmente.

Windows

  1. Baixe second-brain-windows-amd64.exe em Releases e coloque numa pasta própria (ex.: C:\SecondBrain).
  2. Dê dois cliques. O navegador abre em http://localhost:{{.Port}}. Se o Windows avisar, clique Mais informações → Executar assim mesmo e permita no firewall.
  3. Para não depender da janela aberta: Configurações → Este computador → Iniciar com o Windows. A partir do próximo login ele abre sozinho, sem janela. Para parar, use o botão Encerrar o Second Brain na mesma seção.

Computador desligado à noite? Sem problema: o que ficou para trás (backup, atualização, sincronizações, briefing da manhã) roda alguns minutos depois de ligar. Veja Agendamentos.

🐳 Docker na VPS

  1. Instale o Docker: curl -fsSL https://get.docker.com | sh
  2. Crie uma pasta: mkdir -p ~/second-brain && cd ~/second-brain
  3. Com domínio e HTTPS automático (recomendado): 
    curl -fsSLO https://raw.githubusercontent.com/inakano89/second-brain/main/deploy/docker-compose.https.yml
curl -fsSLO https://raw.githubusercontent.com/inakano89/second-brain/main/deploy/Caddyfile
echo "DOMAIN=brain.seudominio.com" > .env
docker compose -f docker-compose.https.yml up -d
    Antes, aponte o domínio para o IP da VPS (registro DNS tipo A) e libere as portas 80 e 443.
  4. Sem domínio (só IP, porta 8080): 
    curl -fsSLO https://raw.githubusercontent.com/inakano89/second-brain/main/docker-compose.yml
docker compose up -d
  5. Abra o endereço no navegador e conclua o setup.

Os dados ficam no volume brain-data. As atualizações automáticas também funcionam no Docker: o binário novo é salvo no volume e usado nos próximos inícios. Para atualizar a imagem: docker compose pull && docker compose up -d. Logs: docker compose logs -f.

🔒 HTTPS e domínio

  1. Tenha um domínio (Registro.br, Cloudflare, Namecheap…) e crie um registro A apontando para o IP da VPS.
  2. Use o arquivo Docker com Caddy acima (certificado gratuito automático) — ou, sem Docker, instale o Caddy com o Caddyfile: brain.seudominio.com { reverse_proxy localhost:8080 }
  3. Em Configurações → Geral → URL pública, informe https://brain.seudominio.com.

⬆️ Atualizações

Por padrão o Second Brain instala sozinho as novas versões publicadas no GitHub (de madrugada, depois do backup), confere a integridade do arquivo, guarda uma cópia do banco e volta à versão anterior se algo der errado. Para desligar: Configurações → Atualizações → botão liga/desliga.

🤖 Automações (avançado)

Permite que a IA acione webhooks (n8n, Home Assistant), MQTT (luzes, tomadas) ou comandos permitidos. Edite a lista em Configurações → Agent actions e ative ACTIONS_ENABLED. Só o que estiver na lista pode ser executado.

⏰ Agendamentos

Formato cron com 5 campos: minuto hora dia mês dia-da-semana. Exemplos: 0 7 * * * = todo dia às 7h; 30 21 * * 1-5 = dias úteis às 21h30; */15 * * * * = a cada 15 min; off desativa.

Rotinas: briefing (7h), tarefas de reuniões (12h e 18h), balanço da noite (21h), memória (22h30), faxina (domingo 17h30) e revisão semanal (domingo 18h), além dos lembretes do Perfil (checados a cada 5 minutos), backup, manutenção e sincronizações.

E se o computador estiver desligado no horário? A rotina roda uma vez quando o Second Brain voltar a abrir (cerca de 2 minutos depois), inclusive a verificação de atualizações e o backup. O briefing da manhã só é enviado até 5 horas depois do horário marcado, o balanço da noite até 3 horas e a revisão semanal até 3 dias; depois disso ficam para o próximo ciclo.

🛟 Problemas comuns

O bot do Telegram não responde
Clique em Verificar bot em Configurações → Telegram. Se o token estiver certo, envie /start e autorize seu usuário.
Google: “redirect_uri_mismatch”
A URI cadastrada no Google precisa ser idêntica a {{.RedirectURL}} (http/https, domínio, porta e barra final).
Google: “ative a … API no Google Cloud Console”
Falta ativar aquela API em APIs e serviços → Biblioteca (veja Google). Ou remova o serviço de GOOGLE_SERVICES.
Google: “permissão não concedida” ou “reconecte”
Em Configurações → Google, clique Reconectar e autorizar e marque todas as caixas.
Takeout: “histórico em HTML”
Refaça a exportação escolhendo JSON em “Vários formatos” para Minha atividade e YouTube.
IA: “Chave inválida” ou “sem créditos”
Confira a chave e o saldo no site do provedor; use Modelos → Testar.
Esqueci a senha
No servidor: second-brain -env .env -reset-password (Docker: docker compose exec second-brain /second-brain -env /data/.env -reset-password).
“Porta em uso” ao iniciar
Outro programa usa a porta. Mude HTTP_PORT no arquivo .env.
Onde vejo o que aconteceu?
Menu Audit log: erros de sincronização, ações da IA, logins e atualizações.
