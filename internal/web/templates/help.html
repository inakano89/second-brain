✅ Primeiros passos

Você não precisa configurar tudo de uma vez. Uma ordem recomendada:

  1. Uma chave de IA (Gemini tem plano gratuito — é o jeito mais rápido de começar). Veja Chaves de IA.
  2. Telegram para capturar notas, áudios e fotos pelo celular. Veja Telegram.
  3. Mais uma ou duas IAs (Claude, GPT) para usar o Conselho, em que os modelos debatem antes de decidir.
  4. Google Agenda/Gmail e Zepp para o briefing matinal ficar completo.
  5. Backup para outro lugar (S3, WebDAV ou Telegram).

Onde colar as chaves: menu Configurações → Variáveis (.env). Campos de senha ficam ocultos depois de salvos (é normal).

🧠 Chaves de IA (API keys)

Uma API key é uma senha que permite ao Second Brain usar a IA de uma empresa. É diferente da assinatura do app de chat (ChatGPT Plus / Claude Pro não servem): a API é cobrada por uso, normalmente centavos por dia.

  • Guarde a chave em local seguro e nunca a compartilhe.
  • Defina um limite de gasto no site do provedor.
  • Depois de colar a chave, vá em Modelos e clique em Testar.

Claude (Anthropic)

  1. Acesse console.anthropic.com e crie uma conta.
  2. Em Billing, adicione créditos (ex.: US$ 5) e, se quiser, um limite mensal.
  3. Abra API Keys → Create Key, dê um nome (ex.: “second-brain”) e copie a chave (começa com sk-ant-). Ela aparece só uma vez.
  4. No Second Brain: Configurações → LLM → Anthropic (Claude) API key → cole → Salvar e aplicar.

GPT (OpenAI)

  1. Acesse platform.openai.com/api-keys e entre.
  2. Em Settings → Billing, adicione créditos.
  3. Clique Create new secret key e copie (começa com sk-).
  4. Cole em Configurações → LLM → OpenAI API key. A OpenAI também habilita a transcrição de voz (Whisper).

Gemini (Google) — tem plano gratuito

  1. Acesse aistudio.google.com/apikey com sua conta Google.
  2. Clique Create API key e copie (começa com AIza).
  3. Cole em Configurações → LLM → Google Gemini API key.

O Gemini lê imagens, PDFs e áudios — ótimo para OCR e transcrição. No plano gratuito o Google pode usar os dados para melhorar produtos; para dados sensíveis, ative o faturamento.

Modelo local (Ollama) — grátis e privado

  1. Instale o Ollama em um computador com boa memória (8 GB+ de RAM).
  2. No terminal: ollama pull llama3.1 (e, para embeddings, ollama pull nomic-embed-text).
  3. Em Configurações → LLM → LLM local, informe http://IP-DO-COMPUTADOR:11434/v1. Se o Second Brain roda no mesmo computador: http://localhost:11434/v1. No Docker: http://host.docker.internal:11434/v1.
  4. Para acessar de outra máquina, inicie o Ollama com OLLAMA_HOST=0.0.0.0.

🧩 Modelos e Conselho

  1. Menu Modelos: cada empresa tem um modelo padrão (★). Adicione ou remova modelos; use “Ver modelos disponíveis na sua conta” para escolher da lista oficial.
  2. Em Qual modelo faz cada tarefa, escolha para cada ação (chat, Telegram, OCR, briefing…) um modelo específico, o padrão de uma empresa, “Automático” ou 🤝 Conselho.
  3. No Conselho, os membros respondem, leem as respostas dos outros e revisam; um moderador escreve a decisão final. Use em decisões importantes (briefing, revisões). É ~7× mais caro que um modelo só com 3 membros e 1 rodada.
  4. No Chat, o seletor no topo troca o modelo na hora; no Telegram use /model.
  5. A lista de modelos se atualiza sozinha. Todo dia o Second Brain baixa a lista recomendada do projeto: modelos novos aparecem, os descontinuados somem e o ★ padrão acompanha a recomendação. Se você escolheu outro padrão, ele é mantido. Para forçar, clique em 🔄 Sincronizar agora; para desligar, desmarque Atualizar lista de modelos de IA automaticamente em Configurações → Atualizações.

Dica de custo: deixe Auto-tagging num modelo barato (ex.: Claude Haiku ou o mais barato de cada empresa) — ele roda em toda nota nova. A página Modelos mostra o preço de cada um (US$ por 1 milhão de tokens).

💬 Telegram (2 minutos)

  1. No Telegram, abra o @BotFather (selo azul oficial) e envie /newbot.
  2. Escolha um nome (ex.: “Meu Cérebro”) e um usuário terminado em bot (ex.: meucerebro_bot).
  3. O BotFather envia um token parecido com 123456789:AAH.... Copie.
  4. Cole em Configurações → Telegram → Token do bot e salve. Os IDs autorizados podem ficar em branco.
  5. Abra seu bot no Telegram e toque em Iniciar (/start). Ele responde com seu ID.
  6. No painel: Configurações → Telegram → Aguardando autorização → Autorizar. Pronto! Só pessoas autorizadas conseguem usar o bot.

O que enviar: texto (conversa com a IA), áudio (vira nota transcrita), foto (OCR), PDF, e comandos como /task comprar pão, /event amanhã 15h dentista, /brief, /help.

📅 Google Agenda e Gmail

É a configuração mais longa (~10 min), feita uma única vez. Você cria um “aplicativo” particular no Google que só você usa.

Pré-requisito: acessar o Second Brain por HTTPS com domínio (veja HTTPS) ou por http://localhost. O Google não aceita IPs nem HTTP em outros endereços.

  1. Abra console.cloud.google.com e crie um projeto (ex.: “second-brain”).
  2. Em APIs e serviços → Biblioteca, ative Google Calendar API e Gmail API.
  3. Em Google Auth Platform (tela de consentimento OAuth): tipo Externo, nome do app, seu e-mail de suporte. Em Público-alvo → Usuários de teste, adicione o seu Gmail.
  4. Em Clientes → Criar cliente: tipo Aplicativo da Web. Em URIs de redirecionamento autorizados, cole exatamente:
    {{.RedirectURL}}
    Se aparecer localhost e você usa domínio, primeiro preencha URL pública em Configurações → Geral.
  5. Copie o ID do cliente e a Chave secreta para Configurações → Google e salve.
  6. Clique Conectar Google. Na tela “o Google não verificou este app”, clique Avançado → Continuar (o app é seu) e permita o acesso.
  7. Importante: em Público-alvo, clique Publicar app (“Em produção”). Em modo “Teste” o Google desconecta a cada 7 dias.

❤️ Zepp / Amazfit

  1. Use o e-mail e senha da sua conta Zepp (se você entra com Google/Apple, defina uma senha no app ou use a alternativa abaixo).
  2. Cole em Configurações → Zepp. A sincronização roda a cada 4 horas (sono, frequência cardíaca em repouso, passos).

A API do Zepp não é oficial e pode mudar. Alternativa estável: envie os dados via webhook (Gadgetbridge, Health Connect + app “HTTP Shortcuts”, Home Assistant) para {{.PublicURL}}/api/health/webhook com o API token (Configurações → Web Clipper & API).

📰 RSS

  1. Encontre o endereço do feed do site (geralmente /feed, /rss ou ícone laranja).
  2. Cole um por linha em Configurações → RSS → Feeds.
  3. Descreva seus interesses (ex.: “IA aplicada, finanças pessoais, corrida”). A IA dá nota 0–10 a cada notícia e salva só as relevantes.

✂️ Web Clipper (salvar páginas)

  1. Mostre a barra de favoritos do navegador (Ctrl+Shift+B).
  2. Em Configurações → Web Clipper, arraste o botão 🧠 Salvar no Brain para a barra.
  3. Em qualquer página, selecione um trecho (opcional) e clique no favorito. Sem seleção, a página inteira é resumida.

📂 Pasta inbox

Arquivos colocados na pasta inbox (ao lado do .env) são lidos automaticamente: PDFs, fotos, áudios, .md, .txt. Depois são movidos para inbox/.archive. Dica: sincronize essa pasta com Syncthing/Dropbox para “jogar” arquivos do celular.

📥 Importar de outros apps

Traga o que você já tem em outros aplicativos: abra Importar no menu, escolha o arquivo exportado e clique em Importar. O formato é reconhecido sozinho, e importar de novo o mesmo arquivo não duplica nada.

  • Obsidian / Logseq: compacte a pasta do vault em .zip (botão direito → Compactar/Enviar para → Pasta compactada) e envie o .zip.
  • Notion: Settings → Export all workspace content → formato Markdown & CSV. Envie o .zip baixado, sem descompactar.
  • Evernote: selecione as notas (ou clique com o botão direito no caderno) → Exportar → formato ENEX.
  • Google Keep: acesse takeout.google.com, clique em Desmarcar tudo, marque só Keep e exporte. Envie o .zip.
  • Favoritos do navegador: Chrome/Edge: Ctrl+Shift+O → ⋮ → Exportar favoritos. Firefox: Ctrl+Shift+O → Importar e fazer backup → Exportar para HTML. Marque “baixar o texto de cada página” para ler os artigos depois.
  • Planilhas (Excel, Google Sheets): Arquivo → Salvar como → CSV. Nomeie as colunas como título, conteúdo, tags, prazo… (linhas com prazo viram tarefas). Exportações CSV do Todoist, Readwise, Goodreads e Pocket também funcionam.
  • Kindle: ligue o Kindle no computador pelo cabo USB e envie o arquivo documents/My Clippings.txt. Cada livro vira um artigo com seus destaques.
  • Contatos: contacts.google.com → Exportar → vCard. No iPhone: iCloud.com → Contatos → ⚙️ → Exportar vCard.
  • Agenda: Google Agenda → ⚙️ Configurações → Importar e exportar → Exportar (baixa um .zip com os .ics). Outlook: Salvar calendário.
  • Feeds (Feedly, Inoreader): exporte o OPML; os feeds entram direto na lista de RSS.

💰 A caixa “Analisar cada item com IA” faz resumo e tags por inteligência artificial, mas custa ~1 chamada por item. Para importar milhares de notas, deixe desmarcada: a busca, as tags e as conexões funcionam mesmo assim. Depois, use “Reprocessar” só nas notas que quiser.

Arquivo muito grande? O limite é IMPORT_MAX_MB (200 MB por padrão, em Configurações → Geral). Se o servidor fica atrás do nginx, aumente client_max_body_size. Ou copie o arquivo para o servidor e rode second-brain -env .env -import arquivo.zip.

🔐 Backup

Os backups são cifrados com a chave mestre definida no setup. Guarde essa chave fora do servidor (gerenciador de senhas) — sem ela não há como restaurar.

  • Telegram (mais fácil): em Configurações → Backup → Destinos, escreva local,telegram. O arquivo chega no seu chat (limite 50 MB).
  • Backblaze B2 / Cloudflare R2 / AWS S3: crie um bucket e uma chave de aplicação; preencha S3_ENDPOINT (ex.: https://s3.us-west-004.backblazeb2.com ou https://<conta>.r2.cloudflarestorage.com), região (auto no R2), bucket e chaves; destinos local,s3.
  • Nextcloud (WebDAV): URL https://sua-nuvem/remote.php/dav/files/USUARIO/backups, usuário e senha de app; destinos local,webdav.

Restaurar: second-brain -decrypt arquivo.db.enc -out brain.db, pare o serviço e substitua data/brain.db.

🖥️ Instalação

Linux (VPS, Raspberry/Orange Pi) — sem Docker

curl -fsSL https://raw.githubusercontent.com/inakano89/second-brain/main/deploy/install.sh | sudo bash

Detecta a arquitetura (x86-64, ARM64 ou ARMv7), verifica o SHA-256, instala em /opt/second-brain, cria o serviço systemd e mostra o endereço. Atualizações automáticas funcionam normalmente.

Windows

  1. Baixe second-brain-windows-amd64.exe em Releases e coloque numa pasta própria (ex.: C:\SecondBrain).
  2. Dê dois cliques e abra http://localhost:{{.Port}}. Se o Windows avisar, clique Mais informações → Executar assim mesmo e permita no firewall.

🐳 Docker na VPS

  1. Instale o Docker: curl -fsSL https://get.docker.com | sh
  2. Crie uma pasta: mkdir -p ~/second-brain && cd ~/second-brain
  3. Com domínio e HTTPS automático (recomendado): 
    curl -fsSLO https://raw.githubusercontent.com/inakano89/second-brain/main/deploy/docker-compose.https.yml
curl -fsSLO https://raw.githubusercontent.com/inakano89/second-brain/main/deploy/Caddyfile
echo "DOMAIN=brain.seudominio.com" > .env
docker compose -f docker-compose.https.yml up -d
    Antes, aponte o domínio para o IP da VPS (registro DNS tipo A) e libere as portas 80 e 443.
  4. Sem domínio (só IP, porta 8080): 
    curl -fsSLO https://raw.githubusercontent.com/inakano89/second-brain/main/docker-compose.yml
docker compose up -d
  5. Abra o endereço no navegador e conclua o setup.

Os dados ficam no volume brain-data. As atualizações automáticas também funcionam no Docker: o binário novo é salvo no volume e usado nos próximos inícios. Para atualizar a imagem: docker compose pull && docker compose up -d. Logs: docker compose logs -f.

🔒 HTTPS e domínio

  1. Tenha um domínio (Registro.br, Cloudflare, Namecheap…) e crie um registro A apontando para o IP da VPS.
  2. Use o arquivo Docker com Caddy acima (certificado gratuito automático) — ou, sem Docker, instale o Caddy com o Caddyfile: brain.seudominio.com { reverse_proxy localhost:8080 }
  3. Em Configurações → Geral → URL pública, informe https://brain.seudominio.com.

⬆️ Atualizações

Por padrão o Second Brain instala sozinho as novas versões publicadas no GitHub (de madrugada, depois do backup), confere a integridade do arquivo, guarda uma cópia do banco e volta à versão anterior se algo der errado. Para desligar: Configurações → Atualizações → botão liga/desliga.

🤖 Automações (avançado)

Permite que a IA acione webhooks (n8n, Home Assistant), MQTT (luzes, tomadas) ou comandos permitidos. Edite a lista em Configurações → Agent actions e ative ACTIONS_ENABLED. Só o que estiver na lista pode ser executado.

⏰ Agendamentos

Formato cron com 5 campos: minuto hora dia mês dia-da-semana. Exemplos: 0 7 * * * = todo dia às 7h; 30 21 * * 1-5 = dias úteis às 21h30; */15 * * * * = a cada 15 min; off desativa.

🛟 Problemas comuns

O bot do Telegram não responde
Clique em Verificar bot em Configurações → Telegram. Se o token estiver certo, envie /start e autorize seu usuário.
Google: “redirect_uri_mismatch”
A URI cadastrada no Google precisa ser idêntica a {{.RedirectURL}} (http/https, domínio, porta e barra final).
IA: “Chave inválida” ou “sem créditos”
Confira a chave e o saldo no site do provedor; use Modelos → Testar.
Esqueci a senha
No servidor: second-brain -env .env -reset-password (Docker: docker compose exec second-brain /second-brain -env /data/.env -reset-password).
“Porta em uso” ao iniciar
Outro programa usa a porta. Mude HTTP_PORT no arquivo .env.
Onde vejo o que aconteceu?
Menu Audit log: erros de sincronização, ações da IA, logins e atualizações.
